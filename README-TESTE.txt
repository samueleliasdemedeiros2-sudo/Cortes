CLIPFORGE PRO - PACOTE DE TESTE

Arquivos:
- index.html: interface atualizada
- server.js: backend atualizado
- package.json: dependencias existentes

Instalacao:
1. Faça backup da versao atual.
2. Substitua os arquivos correspondentes no projeto.
3. Execute npm install (se necessario) e npm start.
4. Mantenha as variaveis de ambiente e configuracoes atuais.

Recursos incluidos nesta versao:
- Editor manual de legendas com exportacao SRT e pre-visualizacao de estilos.
- Sugestoes locais de titulos e hashtags com base nos cortes.
- Deteccao de intervalos silenciosos via FFmpeg.
- Opcao de reenquadramento vertical centralizado (nao rastreia rostos).
- Download em lote dos cortes, um por vez.

Limitacoes importantes:
- Nao ha transcricao automatica de fala/audio nesta versao.
- A pre-visualizacao de estilos nao grava a legenda no MP4; o SRT exportado e texto sem animacao.
- A deteccao identifica silêncios, mas nao remove/une automaticamente esses trechos do video.
- O reenquadramento automatico e centralizado, sem rastreamento inteligente de pessoa/rosto.
- O download em lote consome os pontos normais de cada corte.

Nao foram adicionadas chaves, servicos de IA ou dependencias pagas.
